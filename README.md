# Processor.Ai

> Методическое пособие о том, как научиться вычислять простейшие математические выражения. Например 2 + 2 или (4 - 5)/3, для этого достаточно просто написать собственный виртуальный процессор и все сразу решится само собой!

## Описание проекта
Здесь реализована тьюринг-полная стековая виртуальная машина с собственной системой команд представленной в разделе `Система команд`. В процессоре есть 4 регистра, доступна работа с RAM, а также присутствует видеопамять (реализована через отрисовку оперативной памяти). Присутствует программа ассемблера и дизассемблера.
В разделе `Examples` есть примеры программ, работающих на моем процессоре.

## Архитектура процессора
Структура процессора состоит из:
* массив регистров: `RAX`, `RBX`, `RCX`, `RDX`
* стека для вычислений с элементами типа double 
* стека для адресов возврата
* сегмента кода
* указателя на текущую инструкцию (IP)
* длины кода
* указателя на оперативную память RAM

## Архитектура программы
В заголовочном файле Includes.h подключаются необходимые библиотеки. В остальных заголовочных файлах находятся все обьявления и константы, связанные соотвественно с процессом Ассемблирования, Дизассемблирования, Исполнения, Чтения, Операций со стеком и Видео Памятью.

## Логика работы
* В файле с разрешением `.asm` содержится набор команд для процессора. Модуль `Assembler.cpp` читает этот файл с помощью модуля `Reading.cpp`, далее анализирует каждую прочитанную строку как команду с аргументом (или без него). Для каждой команды определяется ее номер, этот номер записывается в сегмент кода процессора по индексу `IP`. Когда считан номер, читается аргумент, который в свою очередь тоже записывается в сегмент кода по индексу `IP + 1`.
Ассемблер делает два прохода, чтобы обработать метки, которые описаны после своего появления в файле `.asm`. На втором проходе также происходит запись кода в файл `code.txt`, где каждая строка записывается в формате "Номер команды_Аргумент команды".
* Далее происходит исполнение прочитанных команд с помощью модуля `Processor.cpp`. Исполняется команда, на которую в текущий момент указывает `IP`, затем этот индекс сдвигается - это происходит до момента, пока не прочитана инструкция HLT или пока не достигнут конец сегмента кода.
* Следующей запускается модуль Дизассемблирования `DisAssembler.cpp`, который проходит по Сегменту Кода и последовательно дизассемблирует каждую команду со своим аргументом в файл `code.disasm`.
* В самом конце вызывается модуль видео памяти, который выводит на экран графическое представление RAM.

## Режимы запуска и работы
* Компиляция программы происходит с помощью скриптов `build.sh` и `build_debug.sh`. Внутри обоих можно убрать/вставить флаги `STACK_DEBUG`, `PROCESSOR_DEBUG`, `ASSEMBLER_DEBUG` и `GRAPHICS_FLAG` и тогда отключатся/подключатся соответствующие возможности: отладочная информация для стека, процессирования, ассемблирования и отрисовка RAM. 
* В программе есть возможность при запуске задавать файл для исполнения, для этого достаточно написать 
```bash
./a.out <путь_к_файлу.asm>
```

## Система команд
0) HLT - завершает работу программы

1) PUSH - кладет элемент в стек
Команда PUSH кодируется 1 байтом, где 5 младших бит отведены под номер команды `00001`, а 3 младших отвечают соответственно за обращение к стеку (5-й бит), за обращение к регистру (6-й бит) и к оперативной памяти (7-й бит). Причем старшие биты в некоторой комбинации могут быть включены одновременно, например команда PUSH может иметь номер `0b11000001` при вызове PUSH [RAX], эта команда пушит в стек число которое лежит в оперативной памяти по адресу, хранящемся в регистре `RAX`.
Возможные коды команды:
* `0b001000001` - положить обычное число в стек
* `0b010000001` - положить число, лежащее в регистре в стек
* `0b101000001` - положить элемент, лежащий по заданному адресу в `RAM`
* `0b110000001` - положить элемент, лежащий по адресу в `RAM`, содержащемуся в заданном регистре

2) POP - забирает элемент из стека. При отсуствии аргументов просто забирает элемент, а при наличии аргумента-адреса, например как в команде `POP RCX`, забирает элемент из стека и кладет в `RCX`. 
Кодирование команды `POP` полностью аналогично команде `PUSH` за исключением того факта, что бит, отвечающий за то чтобы положить просто число в стек отсуствует.
Возможные коды команды:
* `0b101000002` - взять элемент со стека и положить в `RAM` по заданному адресу
* `0b110000002` - взять элемент со стека и положить в `RAM` по адресу из заданного регистра
* `0b010000002` - взять элемент со стека и положить в заданный регистр
